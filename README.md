# Student Management System (Python)

A professional command-line application designed to manage student records efficiently. This project demonstrates core programming concepts, including Object-Oriented Programming (OOP) and secure data handling.

## 🌟 Key Features
* **Student Class (OOP)**: Utilizes Python classes to structure student data (Name, Class, Grade, Status).
* **Input Validation**: Includes error handling to ensure grades are numeric and within the valid range (0-100).
* **Automated Grading**: Automatically assigns academic status (Excellent, Very Good, Good, Low) based on the entered grade.
* **User-Friendly Interface**: Features a clean CLI with screen clearing and timed transitions for a better user experience.

## 🛠️ Technical Implementation
* **Language**: Python 3.x
* **Error Handling**: Implements `try-except` blocks to manage `ValueError` during user input.
* **Logic**: Uses conditional statements and loops to manage the application flow.

## 📋 How to Use
1. Clone the repository or download the `Students management.py` file.
2. Run the script using: `python "Students management.py"`
3. Use the menu to:
   - **Add a new student**: Enter details and see the auto-calculated status.
   - **Display all students**: View a formatted list of all added records.
   - **Exit**: Close the application safely.
